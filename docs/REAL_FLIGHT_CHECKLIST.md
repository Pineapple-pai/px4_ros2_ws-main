# 真机上电与自主模式检查

这份清单用于光流定位和局部目标控制链路。任何一项不通过时，保持 PX4 原生模式，不切入 ROS 2 自主模式。

## PX4 与定位

- [ ] 确认固件与工作区 `px4_msgs` 版本匹配。
- [ ] 光流传感器已连接、方向正确、数据更新正常。
- [ ] PX4 EKF 已启用光流融合及所需的高度/测距来源。
- [ ] QGC 中本地位置有效且静止时无明显漂移或跳变。
- [ ] RC 模式开关、Position、Land、RTL 和急停/kill switch 已确认。

## ROS 2 与近场测距

- [ ] Micro XRCE-DDS Agent 与 PX4 通信正常。
- [ ] `/fmu/out/vehicle_local_position_v1` 持续更新。
- [ ] 外接测距节点持续发布前、左、右距离，单位为米。
- [ ] 距离方向与机体坐标一致，无遮挡时发布正值的有效量程。
- [ ] 传感器断流或节点停止时，自主模式会保持当前位置。

## 操作顺序

1. 首次接线和参数调试时拆桨并固定机体。
2. 检查 QGC、遥控器、光流定位和测距数据。
3. 在 PX4 原生模式人工解锁、起飞并稳定悬停。
4. 启动 `scripts/start_local_autonomy.sh`，在 QGC 切入 `ROS2 Autonomy`。
5. 发送短距离局部目标，观察响应；出现异常立即切回 PX4 原生模式。

光流只用于运动估计，不提供障碍物检测。绕行安全依赖外接距离节点的覆盖范围、安装方向和数据时效。
